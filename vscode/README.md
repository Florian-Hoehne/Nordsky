# Nordsky for VS Code

Deep-navy dark theme: blue keywords, green strings, orange keys and constants, teal types,
coral numbers. Generated from the shared palette in `../scripts/generate.py`.

Build the installable package with the official VS Code extension tool:

```bash
npm install
```

```bash
npm run package
```

Then install `nordsky-theme-1.0.0.vsix` via *Extensions → … → Install from VSIX…* and pick
**Nordsky** under *Preferences: Color Theme*.
